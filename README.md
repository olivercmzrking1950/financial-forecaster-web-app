Rather than requiring every figure to be interpreted manually, the dashboard uses AI-powered tools to describe financial information in a clearer narrative format. Its plug-and-play design offers a practical foundation for reviewing business performance and making sense of financial activity.

## Installation

First, download the repository and enter its project directory:

```bash
git clone https://github.com/olivercmzrking1950/financial-forecaster-web-app.git
cd Financial-Forecaster-Console
```

Financial Forecaster runs as a web project. You can open its primary HTML file directly in a browser, or host the repository through a local static server.

To start a basic local server, use:

```bash
python3 -m http.server
```

Open the dashboard at:

```text
http://localhost:8000
```
